## 🧐 About <a name = "about"></a>

This is a simple blogging platform that allows users to create posts, edit posts, and delete posts.

### Prerequisites

- Docker
- Postgres database
- Storage S3 compatible
- X (Twitter) [Developer Account](https://developer.x.com/en/portal/dashboard)
- [Github app](https://github.com/settings/apps)
